## 어려웠던 점 3가지와 해결

1. 카드가 화면 폭에 따라 바뀌도록 Grid와 미디어 쿼리를 사용했다.
2. 포스터가 없는 카드에 대체 표지를 넣었다.
3. 상세 페이지에서 포스터와 영화 정보가 2단으로 보이도록 Grid를 사용했다.
